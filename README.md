# Hisobliy – Uzbek Personal Finance Telegram Bot

## About the Project

Hisobliy is a Python-based Telegram bot designed to help Uzbek-speaking users manage their personal finances easily and efficiently.

The project aims to make financial management more accessible by allowing users to interact with a financial assistant in their native Uzbek language.

## Main Features

- Income and expense tracking
- Personal balance management
- Monthly budgeting
- Debt and loan tracking
- Daily and monthly financial reports
- Natural Uzbek language command processing
- Financial transaction history

## Technology Stack

- Python
- Telegram Bot API
- SQLite
- GitHub
- Railway

## Project Goals

Our goal is to simplify financial management for Uzbek-speaking communities and make useful financial tools accessible through Telegram.

## Open Source Development
